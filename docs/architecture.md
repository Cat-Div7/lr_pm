## Key rules

### One page = one folder

Every page lives in `src/pages/page-name/`.
The main page component is always `index.tsx`.
Sub-components that only that page uses live in the same folder.

```
src/pages/catalog/
├── index.tsx           ← the page (exported default)
├── CourseGrid.tsx      ← only used by catalog
├── FilterSidebar.tsx   ← only used by catalog
└── ActiveFilters.tsx   ← only used by catalog
```

If a component is used by **two or more pages**, it moves to `src/components/shared/`.

### `src/components/ui/` is hands-off

This folder is generated by `npx shadcn add ...`.
Do not edit files here manually.
If you need to customize a shadcn component, **extend it** — create a wrapper in `src/components/shared/` that uses the ui component inside.

```tsx
// Correct — wrap it in shared/
// src/components/shared/PrimaryButton.tsx
import { Button } from "@/components/ui/button"
import { cn } from "@/lib/cn"

export function PrimaryButton({ className, ...props }) {
  return (
    <Button
      className={cn("bg-brand-purple rounded-pill font-display font-bold shadow-glow hover:bg-brand-violet", className)}
      {...props}
    />
  )
}

// Wrong — do not edit ui/button.tsx directly
```

### `src/types/index.ts` is shared law

All TypeScript interfaces that cross page/component boundaries are defined here.
Never define a `Course` or `User` type locally inside a component file.
Always import from `@/types`.

### `src/lib/mockData.ts` replaces the backend

Until the real API exists, all components use fake data from this file.
When the backend is ready, you swap the mock import for a real TanStack Query call.
Do not hardcode fake data inline inside components.

## Import alias

The project uses `@/` as an alias for `src/`.
Always use the alias — never use relative paths that go up more than one level.

```ts
// Good
import { CourseCard } from "@/components/shared/CourseCard"
import { useAuthStore } from "@/store/authStore"
import type { Course } from "@/types"

// Bad
import { CourseCard } from "../../components/shared/CourseCard"
```
